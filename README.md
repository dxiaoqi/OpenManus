# AI Agent System

A TypeScript-based AI agent system that supports multiple agent types and tool integrations.

## Features

- 🤖 Multiple Agent Types
  - Base Agent
  - ReAct Agent
  - Tool Call Agent
  - Manus Agent
  - Search Agent
  - Text Agent
  - Data Agent

- 🛠️ Extensible Tools
  - Chat Completion
  - Google Search
  - Browser Interaction
  - File Operations

- 🔄 Flow Management
  - Planning Flow
  - Sequential Flow
  - Parallel Flow (Coming Soon)

- 🎯 Core Capabilities
  - Message Management
  - State Control
  - Error Handling
  - Resource Cleanup

## Installation

```bash
# Install dependencies
npm install

# Build the project
npm run build

# Run tests
npm test
```

## Quick Start

```typescript
import { Manus } from './agent/manus';
import logger from './utils/logger';

async function main() {
  try {
    // Create agent instance
    const agent = new Manus();
    await agent.initialize();

    // Run agent
    const result = await agent.run(
      'Tell me about the solar system'
    );

    logger.info(`Result: ${result}`);
    await agent.cleanup();
  } catch (error) {
    logger.error('Error:', error);
  }
}

main();
```

### Creating New Agents

```typescript
import { BaseAgent } from './agent/base';

export class CustomAgent extends BaseAgent {
  protected async step(): Promise<string> {
    // Implement step logic
    return 'Step result';
  }
}
```

### Adding New Tools

```typescript
import { BaseTool } from './tool/base';

export class CustomTool extends BaseTool {
  constructor() {
    super('custom_tool', 'Tool description', {
      // Tool parameters schema
    });
  }

  async execute(args: any): Promise<any> {
    // Implement tool logic
  }
}
```
